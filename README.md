# 短视频制作 Skills

两条入口，使用同一套可配置的后期规则：

| 输入 | Skill |
|---|---|
| 已剪好的视频，增加字幕、旁白、配乐、花字和装饰 | [short-video-enrichment](skills/short-video-enrichment/SKILL.md) |
| 原始素材文件夹、主题、BF、目标时长，需要选片和粗剪 | [smart-video-editing](skills/smart-video-editing/SKILL.md) |

## 安装与调用

将 skills 下的两个完整目录复制到你的 Codex skills 目录（通常为 ~/.codex/skills）。保留目录名称，以便相互引用。首次使用选择音色、字体和风格，保存到仓库外的个人配置；以后自动复用。

示例：
- “使用 $short-video-enrichment，为这个已经剪好的视频增加旁白、字幕和音乐。”
- “使用 $smart-video-editing，把这份原始素材按 BF 制作成 60 秒亲子短视频。”

## 能力和依赖

这是供 Agent 执行的工作流包，包含一个可运行的本地素材清单工具，尚不是一键全自动剪辑软件。

素材清单需要 Python 和 ffprobe：
`python skills/smart-video-editing/scripts/inventory.py RAW_FOLDER OUTPUT_JSON`

输出放在原始素材目录外。工具识别完全重复文件、读取媒体参数，并按文件大小和修改时间复用缓存；相似镜头、动作、人物表情和原声价值需要额外审阅。

实际制作另需可用的渲染工具、配音服务、字体和音乐。剪映 TTS 工具、账号、字体、音乐以及 HyperFrames 不随仓库分发。剪映桌面智能粗剪必须在使用者环境核实入口、适用素材和桌面控制能力。本仓库尚未完成该桌面环节的端到端验证。失败时明确报告，请用户提供粗剪导出或选择替代流程。

简单字幕和混音可使用 FFmpeg；复杂动效可使用 HyperFrames；最终剪映可编辑多轨草稿需单独验证版本兼容性。适用的已安装 Skill 指令仍需遵守。

## 可复用与验收

保留源素材、镜头清单、配音缓存、时间轴、预览和验收报告。修改文案后按内容和音色重新判断缓存；必须检查音乐是否可听、字幕是否避脸以及配音是否对齐。不能把文件结构校验称作完整视频验收。

Token 节省比例尚无对照实测，不承诺百分比。主要节省来自复用素材分析、配音和脚本，以及减少重复沟通和返工。外部配音服务的用量另计。
