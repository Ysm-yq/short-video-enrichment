# First use and saved profiles

Priority: current instruction > project profile > confirmed personal profile > example defaults.
Public first use: offer 2–3 actually available voices with the same short audition and 2–3 installed font previews on the same real frame. Suggested font categories: playful rounded, clean bold sans, restrained documentary. Check installed font names and available provider voices; do not promise bundled fonts, accounts or voice availability.
Offer mood, caption/flower colors, density and original-audio policy together; save only confirmed choices. Persist a user-level profile outside the public repository for reuse across projects. A project may override it. Do not ask for an already confirmed font on every new project.
For the owner's profile, the confirmed font/colors apply automatically. Offer the saved female voice when starting a new project; explicit “use my defaults directly” is sufficient confirmation. Same-project revisions reuse the voice.

A decoration group means one coordinated cluster (e.g. star pair plus a motion line), not an unbounded number of stickers. 2–4 groups on highlights and 1–2 accents on selected ordinary shots are adjustable ranges, not quotas. Face clearance and readability take precedence.

Render a preview at final resolution for font size; 82px at width 720 scales to 123px at width 1080, but actual glyph metrics vary. Split long lines instead of shrinking all captions. Use relative safe placement and inspect the platform overlay and faces.
